## Where things are

- **[Frames](Frames/)**: who watches, what the formats are, how the channel sounds, and how it earns.
- **[Videos](Videos/)**: one file per video, grouped by series: the hook, the beats, the packaging, the integrations.
- **[Posts](Posts/)**: one file per post, grouped by the same series: the written side of the channel.
- **[Pages](Pages/)**: one file per page of the site: about, sponsors, merch, the newsletter.
- **[Assets](Assets/)**: thumbnails, scripts, b-roll lists, brand files, and sponsor decks the blueprints link to.

## How to use it

A video here describes what the video **is**: why it exists, the hook, the beats, what a viewer leaves with, and what it does not cover. It is not a script and not a task. The `full` variant is the video template; the Format frame holds the rules every video follows. Write the blueprint before the shoot, and keep it true after: a video you shelve stays here, marked `Shelved`, so the reasoning survives.
