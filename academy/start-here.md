# {{Product}}

This is where the school is written down: who it teaches, every course and lesson, and how learners show what they learned. Each page says what something is, whether or not it has been recorded yet.

## What's where

- **[The School](the-school)**: four pages about the school as a whole: what it teaches and why, how it teaches, where it sells, and what a course costs to make. Every new course gets checked against them.
- **[Learners](learners)**: one page for each kind of learner. Teaching a new kind of person? Add a page here.
- **[Courses](courses)**: a folder for each track (a subject), and in it a folder for each course, holding the course's page and a page per lesson. A new course? Add a folder in its track. A new lesson? Add a page in its course's folder. [Welcome to the School](courses/orientation/welcome-to-the-school/welcome-to-the-school.md) shows how the pieces fit.
- **[Paths](paths)**: courses in order, for one kind of learner. Want to say "take these three, in this order"? Add a page here.
- **[Academy](academy)**: the quizzes and flashcards, one set per course. Each quiz asks about one lesson's page. Finished a lesson? Write its quiz here.
- **[Decisions](decisions)**: the big calls behind a course or the school, each signed off by whoever made it. Made a call you'll want the reason for later? Log it here.
- **[Files](files)**: slides, worksheets, recordings, and handouts the pages link to.
- **[Backlog](backlog)**: the to-do board for making lessons, updating courses, and fixing mistakes learners report.

Two more pages sit beside these: the [Catalog](catalog.md), every course as a learner sees it, and the [Lesson Style Guide](lesson-style-guide.md), how a lesson looks and sounds.

## Where to start

1. Fill in the four pages in [The School](the-school), starting with Mission.
2. Read [Welcome to the School](courses/orientation/welcome-to-the-school/welcome-to-the-school.md), then write your first course beside it.

Quizzes need the Academy add-on: on a new computer, run `eidos plugin install` once, then `eidos plugin allow academy`.
