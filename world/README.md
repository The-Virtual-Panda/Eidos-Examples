## Where things are

- **[Frames](Frames/)**: what the world is about, how it feels, how it works, and who plays in it.
- **[Places](Places/)**: one file per place, grouped by region.
- **[Factions](Factions/)**: one file per faction: what it wants, what it holds, what it does next.
- **[Characters](Characters/)**: one file per character the party may meet.
- **[Arcs](Arcs/)**: one file per story arc, grouped by campaign.
- **[Assets](Assets/)**: maps, handouts, reference images, and character sheets the blueprints link to.

## How to use it

A blueprint here describes what a thing **is** in the world: why it exists, what is true of it, what the party sees, and what it is not. It is not a session plan and not a wiki. Write the blueprint before the session, and keep it true after: a truth the players changed is a Decision, and a faction you retired stays here, marked `Retired`, so the reasoning survives. The `revealed` property is the line between what the Game Master knows and what the Player role may read.
