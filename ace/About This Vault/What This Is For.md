# What This Is For

_What this vault is for. Keep it short; a brain does not need a charter, just a sentence it can be held to._

## What This Is For

_A few sentences: what you keep here, what you do with it, and what you want to be true because it exists._

## Not This

_The vault you are deliberately not keeping: the task manager, the file dump, the journal of everything. Writing it down here is what keeps the vault from becoming a junk drawer._
