## Where things are

- **[About This Vault](<About This Vault/>)**: two short pages: what the vault is for, and how it runs.
- **[Atlas](Atlas/)**: what you know: one note per idea, source, or thing, and maps that gather them. Flat; a note finds its place by linking `up` to a map, not by its folder.
- **[Calendar](Calendar/)**: when: daily, weekly, and yearly notes, and any other run of dated notes, grouped by series.
- **[Efforts](Efforts/)**: what you are doing: one note per effort, its heat in `status`. The working notes live in Atlas; the effort says what they are for.
- **[Files](Files/)**: images, PDFs, and files the notes link to.

## The one-page docs

- **[Home](Home.md)**: the front page of the vault: where you start every day.

## How to use it

ACE is Nick Milo's shape for an Obsidian vault: Atlas for knowledge, Calendar for time, Efforts for action. Eidos adds the agreement underneath: each folder has a template per kind of note, each note carries the few properties that make it findable, and two roles say how an agent behaves when you are in the seat and when it is alone. The Atlas template is a title and nothing more, on purpose. An effort's heat is its `status`: On, Ongoing, Simmering, Sleeping, Archived. Change it in the weekly look back.

_Built on Eidos. The page types, the properties each note carries, and the roles live in [`.eidos/`](.eidos/); `eidos check` keeps it honest._
