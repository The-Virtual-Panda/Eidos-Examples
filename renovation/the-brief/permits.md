# Permits

_Permits, inspections, and the rules the work has to meet. The inspector reads this page, and it is why a job cannot start before its paperwork does._

## Who Permits It

_The city, county, or HOA that permits this work, which permits it needs, and what each one covers. Where the permit documents live (link them from Files)._

## Inspections

_Which inspections happen, and at which point in which phase. The gates a job waits on before the next one can cover it up._

## Rules That Change the Design

_The code requirements that shape a room: egress windows, setbacks, GFCI outlets, venting, historic rules. Named here so a room does not promise what the code will not allow._

## Who Signs Off

_The inspector, the engineer, the architect, the HOA: who approves what, and how long they take._
