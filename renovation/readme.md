# {{Product}}

Everything about the renovation in one place: what the finished house should be, what is decided, and what is still open. It stays true from the first quote to the last walk-through.

{{One line: which house, what work, and what life it is for afterward.}}

## What goes where

- **[The Brief](the-brief)**: four pages for the big picture: what you want, the house as it is today, the budget, and the permits. Fill these in first. Everything else gets checked against them.
- **[Rooms](rooms)**: one page per room you're changing, in folders by floor. A new room you're redoing? Add a page here. A room with a lot going on, like a kitchen island, can get pages of its own inside the room's folder.
- **[The Work](the-work)**: one page per job, in folders by phase, from Demolition to Trim-Out. A contractor quoting a job? Write its page here first, so the quote covers exactly what the page lists.
- **[Selections](selections)**: one page per thing you have to choose: a faucet, a tile, a paint color. Each page lists the options you're weighing and the one you picked. Off to a showroom? Start the page before you go.
- **[Change Orders](change-orders)**: any change after the quote is signed, with what it costs and why. Nothing changes until you approve it.
- **[Files](files)**: drawings, permits, quotes, spec sheets, and site photos. Add a file here and link it from the page it belongs to.
- **[Schedule](schedule.md)** and **[Contacts](contacts.md)**: the dates, and everyone on the job, one page each.

The day-to-day work lives on two boards: **On Site** for tasks, inspections, and deliveries, and **Punch List** for the things still to fix near the end. A fix only counts as done once you've checked it yourself.

## Where to start

1. Write [What We Want](the-brief/what-we-want.md): what you're doing, why now, and what you're not doing.
2. Add a page in [Rooms](rooms) for each room you're changing.
