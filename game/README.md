# {{Product}}

This is where the team writes down what the game is: each mechanic, level, character, and item, why it is in the game, and how it plays. The game gets built from these pages and checked against them.

{{One line: what the game is, and who plays it.}}

## What goes where

- **[The Game](the-game)**: five pages about the whole game: its pillars (the few rules every idea has to fit), who plays it, where it runs, how much the team can make, and the games next to it. Fill these in first.
- **[Mechanics](mechanics)**: one page for each thing the player can do, like jumping, a parry, or crafting. Pages that work together share a folder, such as Combat, and a folder can hold smaller ones.
- **[Levels](levels)**: one page for each level, in a folder for each act. When a level has several fights or puzzles, it gets its own folder with a page for each one.
- **[Characters](characters)**: one page for each character the player meets or plays. Enemies go in [Enemies](characters/enemies), and bosses in [Bosses](characters/enemies/bosses).
- **[Items](items)**: one page for each item, upgrade, or collectible.
- **[Decisions](decisions)**: a note for each choice that shaped the game, like a number changed after a playtest or an idea cut. The designer confirms each one, and it shows on the pages it touches.
- **[Files](files)**: art, maps, blockouts, spreadsheets, and the pitch deck. Files that belong together, like a playable prototype or the [Art Bible](files/art-bible) sheets, go in one folder.
- **[Backlog](backlog)**: the work still to do, as a board of tasks, plus bugs from playtests. Playtesters can send bugs through the **Report a Bug** form.

Four pages sit on their own: [The One-Pager](the-one-pager.md) (the whole game on one page), the [Cut List](cut-list.md) (what was cut, and why), the [Playtest Log](playtest-log.md) (every playtest, by date), and the [Art Bible](art-bible.md) (how the game looks and sounds). The **Game Map** canvas draws the core loop, how the parts of the game connect, and the order of the levels.

## Where to start

1. Write the [Pillars](the-game/pillars.md) page: the game in a few sentences, and the three or four rules it keeps.
2. Add a page for the first mechanic you want to try, and say which pillar it serves.

Nothing gets deleted when it is cut. Its page is marked Cut with the reason, so nobody builds it again by accident.
